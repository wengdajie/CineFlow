# 开发与验证脚本

这些脚本不参与运行时，仅用于开发期验证。除 `demo_pipeline.py` / `research_refs.py` 外都需要先启动服务：

```bash
python -m app.main
```

脚本默认访问 `http://127.0.0.1:6060`，可用环境变量覆盖：
`CF_PORT`（换端口）或 `CF_BASE_URL`（换完整地址，如反向代理后的地址）。

| 脚本 | 用途 |
|---|---|
| `smoke_test.py` | 对运行中的实例逐个调用全部 228 项接口用例（含鉴权拦截、自定义站点、追新雷达、热度排行、定时任务改期/重置、插件启停与动作、**网盘总览/浏览/转存**、**ChatOps 指令执行与 Webhook 验签**、**STRM 同步与 302 播放**、**网盘分享追更巡检**、**NFO 补刮与洗版试算**、**在线改配置与恢复默认**、**用户 CRUD 与三档角色 403 边界**、**站点健康探测**、**榜单订阅规则与试算**、**过滤规则组分层试算**、**15 组设置分组**、**搜索每站诊断**、**yt-dlp 付费墙拦截**、**网盘能力位与文件管理全链路**、**网盘凭据保活**、**豆瓣封面兜底**、**图片代理 SSRF 拒绝**），全部通过才退出 0 |
| `ui_check.py` | 用 Playwright 真实浏览器逐页点检 20 个前端页面（含热度排行、定时任务、追新雷达、STRM 同步、分享追更、站点模板/发现弹窗、**站点健康、榜单订阅、过滤规则组、用户权限**），并验证暗色/浅色主题切换真实生效、榜单 tab 切换、定时任务改期弹窗、**网盘管理转存弹窗**、**机器人页指令试跑**、**设置页配置分组**、**STRM 同步弹窗与播放地址复制**、**分享追更表单**、**洗版试算报告**、**站点健康巡检**、**榜单规则弹窗**、**规则组分层试算**、**用户角色表单**、**设置页可编辑控件与恢复默认**；捕获任何 JS 报错与失败请求，截图存 `data/ui_shots/` |
| `demo_pipeline.py` | 用真实磁盘文件演示「解析 → 硬链入库 → 规范命名 → 缺集收敛」全链路，无需启动服务 |
| `verify_docs.py` | 校验 README / scripts/README / `docs/` 里的事实性声明（Provider 数量、端点数、router 数、表数、页面数、测试文件数、主题/热度/定时任务/网盘/ChatOps/刮削/WebDAV/STRM/分享追更/洗版/分类/**可编辑配置白名单/三档角色/站点健康三档/下载器三策略/榜单上限/规则组分层**相关实现、10 篇文档存在且已回填、JSON 示例合法性等）与代码实际一致 |
| `live_check.py` | **联网**验证真实站点闭环：启用 mukaku 预设 → 真实搜索（磁力+网盘）→ 建订阅 → 追新雷达 dry-run 匹配 → 清理 |
| `research_refs.py` | **联网**抓取同类开源项目（MoviePilot / quark-auto-save / SmartStrm / MediaWarp / TgtoDrive 等）的 README 与 topics，提取特性关键词并与本项目已实现能力做差集，产出对标差距表（写入 `docs/09-竞品对标与差距分析.md` 的输入数据）。无网络时输出内置快照，不阻塞 |

`ui_check.py` 需要额外依赖：

```bash
pip install playwright
python -m playwright install chromium
```
