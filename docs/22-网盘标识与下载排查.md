# 网盘标识与下载排查

v1.29.3 在搜索结果的“类型”列显示百度网盘、夸克网盘、阿里云盘、115 网盘等具体平台。来源列仍表示搜索站点。未知链接显示“待识别网盘”，不会按标题猜测平台。

## 下载方式

点击下载时会先显示平台和下载方式：

- **直接下载（不转存）**：使用对应平台账号读取分享原文件，取得直链后交给 aria2。平台不授权直接下载他人分享时，会明确提示。
- **转存后下载**：明确选择此项才会先保存到自己的网盘，再下载本次转存生成的文件。不会下载整个网盘根目录或目标目录中的其他文件。此项是用户主动操作，不受自动转存开关控制。

阿里云盘、115 和百度的授权及下载权限仍由各平台决定。失效、被取消的分享不能通过转存恢复；应更换有效链接。URL 自带的 `pwd`、`passcode` 或 `password` 参数会作为提取码，手填提取码优先。

网盘中的 `.torrent` / Metalink 文件按原文件下载，不会自动派生 BT 或其他下载。普通 BT 资源入口保留原来的种子跟随行为。

## 失败提示

解析失败不会再把按钮显示为“已添加”。下载任务页会保留具体错误，不能仅凭存在一条任务判断已开始下载。

| 提示或现象 | 处理方式 |
|---|---|
| 好友已取消了分享（如夸克 code=41012） | 更换有效分享，重新下载 |
| 百度 Cookie 无效（errno=-6） | 在网盘管理重新登录百度，或使用适用的开放平台授权；夸克账号无法用于百度资源 |
| aria2 当前不可用 | 启动 aria2 并检查 RPC 地址、端口和密钥；Docker 内不要把另一个容器写成 127.0.0.1 |
| 平台要求先转存 | 选择“转存后下载”，或在官网处理；普通直接下载不会隐式转存 |
| 转存已提交但未确认完成 | 先在网盘确认状态，避免反复提交；确认后可从网盘文件列表选中下载 |
| 未确认具体落地文件 | 从网盘文件列表选择本次文件，不会退回下载整个目录 |
