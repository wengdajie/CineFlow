## 同一订阅使用同一剧集目录

订阅名称、季号、媒体类型和年份决定入库身份；字幕组、宣传前缀、资源标题中的不同年份或季号不再决定目录。单集的集号、画质等信息继续从文件解析。

未单独指定保存路径时，后续订阅下载按剧名和季归档，例如：

```text
K:\media\tv\死神 千年血战篇 -祸进谭\Season 01\
```

订阅中明确指定的下载路径继续生效。下载完成后统一整理到媒体库：

```text
K:\media\library\死神 千年血战篇 -祸进谭\Season 01\
    死神 千年血战篇 -祸进谭 - S01E01.mkv
    …
    死神 千年血战篇 -祸进谭 - S01E07.mp4
    死神 千年血战篇 -祸进谭 - S01E08.mkv
```

## 网盘资源下载到本地

在“网盘管理”选择已登录的网盘，文件和目录操作区均可点击“下载到本地”。应用换取临时 HTTP 直链，然后提交给 aria2，在“下载任务”查看进度。

- 保留网盘要求的 User-Agent 和原始文件名。
- 目录逐文件下载，保留子目录，跟踪全部 aria2 GID；暂停、恢复、移除作用于全部文件。
- 所有文件都下载完成后，整条任务才进入完成及整理流程。
- 云端转存成功而本地投递失败时，任务保持待处理并显示原因，不再误报为已入库。已记录的转存位置用于重试，避免再次转存同一分享。
- 不把网盘根目录当成某个分享的内容；百度转存结果提供文件路径时，只处理这些路径。
- 不完整目录不提交部分文件；单次目录下载限制为 8 层、200 个文件，超限需选择较小目录。

真实百度网盘测试返回 `errno=-6`，现有 Cookie 已失效。用户选择“暂不登录，先完成其他修复”，因此本轮不继续百度实盘验证。后续可在“网盘管理”重新扫码登录后再验证真实百度下载，本轮没有声称百度实盘下载成功。

已使用本机 WebDAV 测试目录，通过真实 CineFlow API 和真实 aria2 完成两个文件的下载，子目录和 SHA-256 均一致。这验证了本地传输链路，不代表已经通过百度等外部网盘的鉴权。
