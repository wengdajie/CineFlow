# 搜索响应与多网盘下载修复

## 本轮行为

1. 热度排行的“搜资源”跳转后自动发起一次查询。返回结果页不会重复发起查询。
2. 流式接口先返回开始事件，片名别名查询最多等待 2 秒。站点等待并发名额的时间不再扣减该站请求预算。每个站点完成后独立显示资源；渲染错误会显示错误提示，不再被当作 JSON 解析错误吞掉。
3. 网盘下载交给 aria2，传递平台要求的 User-Agent、Referer、Cookie。新增阿里云盘存储 Provider 与账号预设，支持令牌刷新；115 使用加密的 app 下载接口。多文件任务继续跟踪全部 GID，全部完成后才能整理入库。
4. 普通下载默认 `pan_mode=download`，只读取对应平台的分享原文件，不转存。缺少对应账号时说明该平台的配置要求，不再退回百度账号。显式 `save_then_download` 与独立“转存”按钮保留原操作。
5. 待处理队列增加单条重试；批量重试保留原意图。旧版未标注意图、也未取得保存路径的任务按分享下载重试，避免升级后继续隐式转存。

临时直链与请求头只用于提交下载器，不写入下载任务元数据。阿里云盘刷新后的凭据存入站点私密字段，不通过站点列表的 options 返回。Cookie 只附加给对应平台 HTTPS 域名。

## 使用方式与边界

- 夸克、百度、115 可使用已有账号登录入口。阿里云盘从“设置 → 站点管理 → 自定义站点预设 → 阿里云盘”添加；本人 Web 账号 refresh_token 填密码字段，access_token 可填 API Key 字段。无需两个字段同时填写。
- 搜索结果的“下载”尝试读取已授权的分享原文件。平台未授权分享直下时会停止并明确提示；尤其夸克分享通常需要先由用户明确转存，再在网盘文件列表点击“下载到本地”。不会为了获得地址偷偷执行转存。
- 网盘文件列表中的“下载到本地”下载已选文件或目录，可用于不同网盘；分享页面 URL 本身不会当作媒体文件交给 aria2。
- 提取码、账号授权、下载权限及平台限制仍适用。未取得全部文件直链、目录未完整列出或路径无效时，不提交部分任务。
- 百度现有 Cookie 已失效，用户选择暂不登录；夸克、阿里云盘、115 也未提供有效测试账号。因此本轮没有验证这些外部网盘的实际文件下载，不能把接口模拟测试等同于实盘成功。

## 验证证据

- 隔离 Chromium：热榜点击只发出 1 次搜索；首条资源 235 ms 可见，慢站点 4213 ms 完成；返回结果页不重复查询，脚本错误为 0。截图可见“搜索中 1/2 站”与已返回资源同时存在。
- 真实本地 aria2：HTTP 测试端强制校验 Cookie、Referer、User-Agent；两个文件（253952 字节、106496 字节）下载完成，逐字节及 SHA-256 校验一致，保留子目录。该测试没有连接外部网盘。
- 本机实际启用站点搜索“死神”：开始事件 438 ms，首批 18 条资源 1969 ms 返回，全部站点 28016 ms 结束。首批可用结果无需等待全部站点；末站完成时间仍受网络、排队与站点超时影响。
- 新版真实 API：8 个存储 Provider 可见，默认下载模式为 `download`；临时夸克下载任务提示对应平台账号要求，转存记录增量为 0，临时任务已删除且没有删除媒体文件。重启前使用 SQLite backup API 备份数据库至 `.tmp/search-pan/pre-restart.db`。
- Python 3.10 与 3.12 全量测试各 **1792 项通过**，各有一条已有的 Starlette TestClient 迁移提示。Ruff 通过；文档校验 1435/1435、YAML 与部署校验 120/120、6 个前端模块检查及两套 Python 的项目事实校验通过。
- 回归覆盖默认下载不转存、跨平台账号隔离、旧任务重试、账号令牌轮换及接口隐藏、115 协议参考向量、平台请求头和路径校验。
- 本地证据位于 `.tmp/search-pan/`，包括 `browser-result.json`、`first-results.png`、`aria2-result.json` 和测试日志；均被 Git 忽略。
