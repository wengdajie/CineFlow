# 深度审查与本地验证

本轮按可复现问题迭代：先证明问题，再修复，再验证修复及相邻边界。

## 审查范围

- 认证、角色、站点凭据与配置读写。
- 下载投递、下载器归属、多文件状态、并发删除及重试。
- 整理覆盖、媒体库移动、网盘根目录与路径边界。
- 订阅缺集、部分入库、网盘目录解析与请求数量。
- 浏览器交互、全量回归、实际本地服务与下载器。

## 第一轮

已为以下问题加入隔离复现：缺失下载器回退到其他实例、站点 options 暴露凭据、静态 API Token 选中已禁用管理员、整理覆盖删除源文件或旧媒体、本地网盘允许删除根目录、绝对命名模板越过媒体库目录。

真实媒体不用于破坏性验证。百度暂不重新登录，外部网盘只报告可验证范围。
